# V1.1 需求规格说明书 — 评分严格化 & Windows 适配

## 1. 背景

V1 版本已完成基础功能（实时检测、评分、提醒、校准、统计），但存在两个问题：

1. **评分过于宽松**：用户随意摆姿势也能获得 60-85 的高分，前倾提醒几乎不触发，失去纠正意义
2. **仅支持 macOS**：计划中声明跨平台，但当前代码存在 macOS 专有 API，需适配 Windows

## 2. 需求一：评分严格化

### 2.1 问题分析

**当前评分逻辑缺陷：**

| 缺陷 | 说明 |
|------|------|
| 默认基线太宽容 | 未校准时假设"每人天生前倾 4-5°"，等于内置免罚额度 |
| 惩罚系数太低 | 每个维度的偏差扣分太轻，偏离很大才能把分数拉下来 |
| 缺乏非线性惩罚 | 偏离 5° 和偏离 15° 每度的扣分一样，不符合直觉（中度偏离就该提醒） |

**实际数据验证（当前代码）：**

| 姿态 | 头前倾 | 脊柱 | 肩膀 | 当前评分 |
|------|--------|------|------|----------|
| 端正坐姿 | 2° | 1.5° | 1° | 91 |
| 轻微前倾 | 8° | 6° | 2° | 84 |
| 明显驼背 | 10° | 8° | 3° | 66 |
| 严重驼背 | 15° | 12° | 4° | 37 |

问题场景：**轻微前倾和明显驼背仍能拿到 66-84 分，用户感觉"随便坐都高分"。**

### 2.2 目标

- **端正坐姿** → 90-100 分（绿色）
- **轻微前倾**（头前倾 6-8°，脊柱 5-6°）→ 60-75 分（黄色）
- **明显驼背**（头前倾 10°+，脊柱 8°+）→ 20-50 分（红色）
- **严重驼背**（头前倾 15°+，脊柱 12°+）→ 0-20 分（深红色）

### 2.3 功能需求

| ID | 需求 | 说明 |
|----|------|------|
| S1 | 提升惩罚系数 | head: 6.67→12，spine: 10→18，shoulder: 20→30，使每度偏差扣分增加约 1.8-2 倍 |
| S2 | 收紧默认基线 | 未校准时基线 head: 1.5° / spine: 1.0° / shoulder: 0.5°，接近完美竖直 |
| S3 | 校准后仍严格 | 即使校准过，偏离基线超过阈值的扣分速度不变，校准只是"把 0 分点对准你的身体" |
| S4 | 测试覆盖 | 更新 PostureScorer 和 AlertManager 测试用例，验证新评分梯度 |

### 2.4 验收标准

- 端正坐姿（各角度接近基线）评分 ≥ 90
- 明显驼背（头前倾 ≥ 10° 或 脊柱 ≥ 8°）评分 ≤ 50
- 前倾提醒（阈值 < 50）能正常触发
- 现有测试全部通过

## 3. 需求二：Windows 适配

### 3.1 问题分析

| 文件 | 问题 | 影响 |
|------|------|------|
| `electron/main.ts` | `titleBarStyle: 'hiddenInset'` 是 macOS 专有 API | Windows 上窗口无标题栏，无法拖拽/关闭 |
| `electron/tray.ts` | `tray.on('click')` 在 Windows 上的行为与 macOS 不同 | Win 上左键单击托盘图标默认显示右键菜单，窗口 toggle 逻辑失效 |
| `electron-builder.yml` | 缺少 Windows 图标路径 | 打包后 .exe 显示默认 Electron 图标 |
| `electron/tray.ts` | 托盘图标尺寸固定 22px | Windows 托盘图标建议 16/32px，当前方案可用但可能模糊 |

### 3.2 功能需求

| ID | 需求 | 说明 |
|----|------|------|
| W1 | 窗口样式平台适配 | macOS 用 `hiddenInset`，Windows 用默认标题栏 |
| W2 | 托盘行为平台适配 | macOS 左键切换窗口显隐，Windows 左键显示 Dashboard + 右键菜单 |
| W3 | 通知平台适配 | 使用 Electron Notification API（已跨平台），无需改动 |
| W4 | 打包配置 Windows | 添加 Windows 图标，配置 NSIS 安装器 |
| W5 | 应用图标 | 生成跨平台图标资源（.icns / .ico / .png） |

### 3.3 验收标准

- Windows 10/11 上窗口正常显示，标题栏可拖拽、最小化、关闭
- 托盘图标显示，左键打开 Dashboard，右键弹出菜单
- 系统通知正常弹出
- `npm run dist` 能成功打包 Windows .exe 安装包

## 4. 非功能需求

- 改动集中，不影响 Dashboard/Stats/Settings 页面功能
- 类型检查零错误
- 不影响 macOS 现有体验
- 打包后 Windows 安装包 < 200MB
